# CareerBridge AI

## About
CareerBridge AI is a Women's Hackathon project built using AWS PartyRock. It helps first-generation women learners with limited professional networks turn career aspirations into achievable and personalized career plans.

## Selected Problem Statement
**Problem Statement 2: Education and Careers – From Aspiration to an Achievable Plan**

### Selected Persona
**A first-generation learner with limited professional networks**

## Key Features
- Career Discovery
- Transferable Skills Map
- Skill Gap Analysis
- 90-Day Career Plan
- Weekly Learning Schedule
- Learning Resources
- Proof of Learning
- Network Builder
- Recovery Plan
- Career Readiness Score

## Technology
- AWS PartyRock
- Generative AI

## Solution
The app assesses the user's education, skills, experience, goals, available time, budget, confidence and professional network. It then generates a personalized career direction, identifies transferable skills and gaps, creates an achievable learning plan, and provides practical next steps.
